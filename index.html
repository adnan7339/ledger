Your link points to an uploaded Excel file, which the web cannot read directly. Convert it once:

  1. Open the file in Drive → File → Save as Google Sheets.
  2. On the new sheet: Share → General access → Anyone with the link → Viewer.
  3. Copy that new link into the field above and press Load from Google Sheet.
